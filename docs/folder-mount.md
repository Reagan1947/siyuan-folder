# 思源笔记 Folder：嵌在文档里的资源文件夹

调研日期：2026-10-21。对照 FlowUs 嵌在普通页面里的文件夹块，以及思源 3.8.3 起的自定义块。文件仍放在思源的 `data/assets`，不另建一套存储。

## 结论

文件夹是文档正文里的一个自定义块，和段落、图片排在一起。用 `/folder`、`/wjj` 或「文件夹」插入。块里只记下资源目录和当前视图；文件本身在 `/data/assets/folder/{id}/`。

这对齐的是 FlowUs **嵌在页面里的文件夹块**：两种视图、在块里进入子文件夹、新建文件夹、上传文件。FlowUs 左侧目录树里那种独立的文件夹页面，以及它的列表、缩略图、大图，不在这里做。

上一版侧栏浏览整个工作空间。那个范围把 `plugins`、`templates`、笔记本原始目录也摊开了，和「资源放在 assets、文件夹嵌在页面里」不是同一件事。界面是文档里的这个自定义块，不再使用侧栏。

## 和 FlowUs 嵌入块对齐的部分

- 文件夹出现在页面正文中，由斜杠命令创建
- 块内切换两种视图，名称沿用 FlowUs：
  - **标题**：一行一个名称
  - **卡片**：格子。图片显示缩略图，其他文件显示类型图标，名称在下面
- 在块里新建子文件夹，上传文件，也可以一次上传整个本地文件夹并保留相对路径
- 点进子文件夹仍留在同一个块里，用面包屑返回

## 保持不同的部分

- 字节存在 `data/assets`。块内容里写一条以 `/` 结尾的资源链接，思源把该目录下的文件都算作已引用，清理未引用资源时不会删掉它们
- 不做成新的页面类型，不出现在文档树里
- Office、PDF、音视频只显示名称和修改时间
- 不做分享密码、外部协作者、批量下载配额、页面历史
- 不读工作空间以外的路径，也不浏览 `conf`、`repo`、笔记本 `.sy`、`plugins`、`templates`

## 块里存什么

自定义块从思源 3.8.3 可用，类型声明从 `siyuan@1.2.6` 起。`plugin.json` 的 `minAppVersion` 改为 `3.8.3`。

围栏信息是 URI 编码后的插件名和块类型。插入后的 Markdown：

```markdown
;;;siyuan-folder/folder
[folder](assets/folder/20261021113000-a1b2c3d/)
title
;;;
```

两行都有固定含义：

- 第一行是资源链接，目录名以 `/` 结尾。`{id}` 在插入时生成，形如思源的时间戳加随机串，只含字母、数字和连字符
- 第二行是视图，只能是 `title`、`card`。曾经写过的 `preview`，以及缺省或无法识别时，用 `title`

文件清单不写进块。渲染时对当前目录调用 `/api/file/readDir`。视图切换才调用 `setContent`，把第二行换掉，第一行保持不变。进入子文件夹只改内存里的相对路径，不写回文档，避免每次点击都产生一篇文档变更。

复制这个块会复制这两行，两处块看同一份资源。这和思源「同一条资源链接可以被多处引用」一致。另存为一份新目录留到后面，不在这一版做。

插件没加载时，思源显示这段原始内容。链接仍然指向资源目录，发布页也如此。`disabledInPublish` 保持 `true`：`readDir` 和 `putFile` 只允许管理员调用，发布页不渲染交互界面。

渲染只改传入的挂载元素，可以返回清理函数。挂载元素里不嵌 Protyle。`setContent` 放在渲染返回之后的事件里；只读，或内容里出现独占一行的 `;;;` 时，它返回 `false`，界面保持原样。

## 资源目录

只用全局 `/data/assets/folder/{id}/`。不用笔记本旁边的 `assets`：笔记本级资源没有数据历史，不能用 `/资源` 搜索，删除笔记本时还会被复制到全局资源。

插入块时先 `POST /api/file/putFile`，`path` 为该目录，`isDir` 为 `true`，再把自定义块插到光标处。目录创建失败则不插入块。

之后所有读写都先把路径规范化，再确认它等于这个目录，或者是它的子路径。`..`、绝对路径、其他 `assets` 子目录、`/data/assets` 本身，都不接受。符号链接只显示「符号链接」，不进入、不上传到它里面。

新建名称和上传文件名交给内核的上传文件名校验。点号开头的名称不创建，列表里也不显示。单层超过 5000 项就停止渲染并提示。

上传用同一个 `putFile`，`isDir` 为 `false`，写到当前所在的那一层。一次上传整个文件夹时，按相对路径逐个写入，路径仍必须落在该块目录内。空子文件夹用 `isDir=true` 创建。

`putFile` 会推进思源同步。这些文件是普通资源，会进入 `data/` 快照。视图切换改的是 `.sy` 里的第二行，同样会同步。轮询得到的列表只放内存，不写进 `data/storage`。

## 打开

单击目录进入该层。单击文件用系统默认应用打开，只打开落在该块资源目录里的本地路径；符号链接不打开。桌面端不可用时提示失败。卡片视图里，图片显示缩略图：流式读取 `/api/file/getFile`，超过 20 MiB 则只显示名称和修改时间。用 `blob:` URL，块被清理时释放。其他文件只显示名称和修改时间。

`readDir` 不返回大小。标题视图里的文件大小来自单独的资源统计。

块可见且页面在前台时，对当前这一层每 3 秒 `readDir` 一次。间隔放在设置里，范围 2–30 秒。折叠或滚出视野后的层不请求；上一轮没回来就跳过。快照用「路径 + 是否目录 + 是否符号链接 + `updated`」。集合变了就重绘，只有修改时间变了就更新那一项。某一层失败时保留当前画面并标出失败。

## 明确不做

- 不读取工作空间以外的路径
- 不把目录收成笔记本，不写 `.sy`，不进全文搜索
- 不用挂件，不用 iframe，不用侧栏
- 不在这一版改名、删除。上传和新建已经会改资源目录；删除留到目录边界再核对过之后
- 不在发布页提供交互

## 安全

插件和当前管理员能调用的文件 API 是同一权限。这个块把可写范围收成它自己的那一个资源目录。

- 请求路径只允许规范化之后、落在 `/data/assets/folder/{id}/` 下的路径
- 块内容里的链接若指向别处，渲染时报错，不按那个路径发请求
- 不沿符号链接下钻
- 卡片缩略图有字节上限
- `disabledInPublish: true`

## 分期

**第一期。** 斜杠插入、创建资源目录、两种视图、进入子文件夹、卡片里的图片缩略图、上传文件、新建子文件夹、当前层定时刷新。到这里就可以嵌在文档里用。

**第二期。** 在该目录内改名和删除，以及把选中文件的资源链接插到光标处。删除前仍要确认路径在该块目录内。

**第三期再考虑。** 块内文件名搜索（限制深度和条数）、桌面端「在文件管理器中显示」。

工作空间以外的系统文件夹不在这个插件里做。

## 验证

- `/folder` 插入后，文档里出现自定义块，并且 `data/assets/folder/{id}/` 已创建
- 块的 Markdown 含有以 `/` 结尾的 `assets/folder/{id}/` 链接。把一个文件放进该目录后，它不出现在「未引用的资源文件」里
- 标题、卡片可以切换；重新打开文档后视图还在，当前子目录回到根
- 上传的文件出现在当前层，路径仍在该块目录下。上传带 `../` 的相对路径会被拒绝
- 子文件夹可以进入，面包屑可以回到根。进入子文件夹不改文档内容
- 大于 20 MiB 的图片在卡片里只显示名称和修改时间。符号链接可见，不会进入
- 复制块之后，两处显示同一目录里的文件
- 发布页不渲染交互界面，原始内容里仍能看到资源链接
- 插件未启用时，文档显示原始 Markdown，不出现空白块
