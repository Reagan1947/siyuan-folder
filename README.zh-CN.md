## 功能

- [x] 用 `/folder`、`/wjj` 或 `/文件夹` 插入文件夹
- [x] 在块内切换标题视图和卡片视图
- [x] 在同一个块里进入子文件夹，并用面包屑返回
- [x] 新建子文件夹、添加文件，或上传本地文件夹并保留相对路径
- [x] 在文件夹内重命名和删除
- [x] 在光标处插入所选文件的资源链接
- [x] 按文件或文件夹名称搜索
- [x] 按名称、创建时间或大小排序
- [x] 卡片视图中显示图片缩略图
- [x] 用系统默认应用打开文件
- [x] 在桌面端于文件管理器中显示
- [x] 按间隔重新读取当前可见的这一层

## 用法

**插入文件夹**

在编辑器中输入 `/folder` 或 `/wjj`，然后选择思源文件夹。思源会创建 `data/assets/folder/{id}/`，并把块插入到光标处。目录创建失败时，不会插入任何内容。

**切换视图**

使用块内的视图切换。

- **标题：** 一行一个名称，并显示创建时间和大小。
- **卡片：** 格子布局。图片显示缩略图，其他文件显示类型图标，名称在下面。

所选视图会保存在块里。当前打开的子文件夹不会保存：重新打开文档后，回到该文件夹的根目录。

**浏览**

单击文件夹进入该层。面包屑可以返回上级或根目录。根目录上显示的名称可以修改。

单击文件，用系统默认应用打开。在桌面端，项目菜单可以把该项显示在文件管理器中。符号链接会列出来，但不能打开，也不能进入。

**添加文件**

- **添加文件** 把选中的文件写入当前这一层。
- **添加文件夹** 上传本地文件夹并保留相对路径，包括空的子文件夹。
- **新建文件夹** 在当前这一层创建子文件夹。

名称由思源校验。以点开头的名称会被拒绝。会离开这个文件夹的路径也会被拒绝。

**重命名、删除和插入链接**

使用项目菜单重命名或删除一项。可以选中多项后一起删除。删除不能撤销。

**插入链接** 会把该文件的资源链接放到当前编辑器的光标处。

**搜索和排序**

搜索匹配当前文件夹下的文件名和文件夹名，最多 6 层、200 条结果。可以按名称、创建时间或大小排序。排序只在停留于该块期间保留。

**图片**

卡片视图中，小于 20 MB 的图片显示为缩略图。更大的图片只显示名称和修改时间。

**刷新**

块可见时，当前这一层默认每 3 秒重新读取一次。可在插件设置中修改，间隔为 2 到 30 秒。折叠或滚出视野的层不会请求。

**文件放在哪里**

每个块拥有一个目录：`data/assets/folder/{id}/`。块里保存指向该目录的链接。思源把其中的文件视为已引用资源，清理未引用资源时会保留它们，它们也会跟随思源同步。

复制这个块会复制该链接。两个块显示同一批文件。

这个块不浏览工作空间的其他位置，也不读取它自己的资源目录以外的路径。

**发布**

发布页不渲染可交互的文件夹。文档里仍保留资源链接。插件被禁用时也是同样的回退显示。
